# 🌍 Moatez Voyages - Site Web Agence de Voyage

Bienvenue dans le projet **Moatez Voyages**, un modèle de site web moderne, élégant, fluide et 100% responsive conçu en **HTML5** et **CSS3** purs, sans frameworks complexes.

---

## 📁 Structure des Fichiers

```text
projet moatez/
│
├── index.html        # Fichier principal : structure sémantique du site web
├── style.css         # Feuille de style CSS : design moderne, grille et responsive
└── README.md         # Guide d'utilisation et personnalisation du projet
```

---

## ✨ Fonctionnalités & Sections Incluses

1. **Barre de Navigation (Header)** : Logo avec icône d'avion, liens d'ancrage fluides et bouton d'action rapide.
2. **Bannière Principale (Hero Section)** : Titre accrocheur, image de fond immersive et barre de recherche rapide (destination, dates, voyageurs).
3. **Destinations Populaires** : Grille de 6 cartes avec photos haute définition, prix, notes étoiles et détails de séjour.
4. **Pourquoi Nous Choisir (Services)** : 4 engagements forts (Meilleur prix, support 24/7, sécurité, sur-mesure).
5. **Offres Spéciales** : Bannière promotionnelle avec dégradé moderne pour convertir les visiteurs.
6. **Avis Clients (Témoignages)** : Retours d'expérience avec avatars et notations.
7. **Formulaire de Réservation & Contact** : Coordonnées réelles (adresse, tél, email) et formulaire de devis.
8. **Pied de Page (Footer)** : Liens utiles, réseaux sociaux et inscription à la newsletter.

## 🎨 Comment Personnaliser le Projet ?

### Changer les couleurs
Toutes les couleurs principales sont regroupées en haut du fichier `style.css` sous `:root` :
```css
:root {
    --primary: #0284c7;        /* Couleur bleue principale */
    --secondary: #f97316;      /* Couleur d'accent orange */
    --dark: #0f172a;           /* Couleur des textes sombres */
}
```

### Modifier vos coordonnées
Ouvrez `index.html` et cherchez la section `<section class="contact"` pour modifier :
- Le numéro de téléphone
- L'adresse email
- L'adresse postale
